Imágenes para tu sitio con una dirección visual coherente

Para sitios que necesitan imágenes editoriales o ilustraciones adaptadas a cada diseño.

Dónde puedes usar las imágenes

Banners de inicio, tarjetas de servicios e imágenes editoriales, con dimensiones acordes a cada ubicación.

De la dirección visual a imágenes listas para publicar

Propuesta visual
Definimos el ambiente, las proporciones y las ubicaciones según el diseño del sitio.
Generación de imágenes
Creo recursos listos para web dentro del cupo acordado. Los paquetes de desarrollo incluyen hasta 10 imágenes.
Ajustes
Usa las revisiones incluidas para afinar las imágenes aprobadas y prepararlas para el sitio.

Ejemplo de propuesta visual para un sitio de bienestar

El inicio necesita una escena panorámica con espacio para el título. Las tarjetas de servicios necesitan encuadres más cerrados que compartan la luz y la paleta. Planificamos cada composición para su ubicación.

Cómo planifico imágenes con IA para un sitio web

Diseñar según dónde irá cada imagen

La imagen principal puede necesitar espacio libre para el título. En cambio, una tarjeta necesita un motivo que se entienda en un espacio reducido. Planifico la orientación, la composición y el color según el diseño. Una dirección visual compartida da coherencia a toda la serie.

Preparar las imágenes aprobadas para web

Reviso las imágenes elegidas al tamaño en que se mostrarán y las exporto para cada ubicación. Antes de publicar, podemos comprobar los recortes para móviles y redactar texto alternativo para las imágenes informativas. Los paquetes incluyen hasta 10 imágenes generadas y 3 revisiones de imagen en total.

Preguntas frecuentes

¿Puedes seguir la dirección visual de una marca?
Sí. Comparte la paleta, las referencias visuales y dónde irán las imágenes para definir una dirección coherente.
¿Qué cuenta como una revisión de imagen?
Una revisión corresponde a una imagen. Los paquetes de desarrollo incluyen hasta tres revisiones de imágenes en total.
¿Necesito imágenes generadas para todas las páginas?
No. Elegimos las ubicaciones donde aportan al contenido. Puedes combinar fotografías propias con imágenes generadas. Las fotografías documentales deben representar con precisión su material.
