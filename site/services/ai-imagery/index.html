Website imagery with a consistent visual direction

For websites that need cohesive editorial or illustrative assets suited to specific page layouts.

Where the images can go

Homepage banners, service cards and supporting editorial visuals, sized for their intended placements.

From visual brief to web-ready assets

Visual brief
Set the mood, aspect ratios and placements around the site design.
Image generation
Create website-ready assets within the agreed allowance. Build packages include up to 10 images.
Refinement
Use the included image revisions to fine-tune approved selections and prepare them for the site.

Example brief for a wellness website

The homepage needs a wide scene with space for the headline. The service grid needs tighter crops that share its light and palette. We plan each composition for the placement it will occupy.

How I plan AI-generated images for a website

Design the images around placements

A hero image may need open space for a headline, while a service card needs a subject that reads clearly in a smaller crop. I plan orientation, composition and color around the actual layouts. A shared visual brief helps a series of images feel consistent across the site.

Prepare approved imagery for the web

I review the selected images at their intended sizes and export them for the relevant page placements. Before publishing, we can check responsive crops and write alt text for images that carry information. Website build packages include up to ten generated images and up to three image revisions in total.

Frequently asked questions

Can you match a brand’s visual direction?
Yes. Share the palette, existing visual references and intended page placements so we can define a consistent direction.
What counts as an image revision?
An image revision applies to one image. The build packages include up to three image revisions in total.
Do I need generated imagery for every page?
No. We choose placements where it supports the content. Your own photography can sit alongside generated imagery, and documentary images should accurately represent their subject.
