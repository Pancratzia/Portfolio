What I build with Oxygen for WordPress

Decide when a template should do the work

For a WordPress site with recurring content, I define which screens are one-off pages and which should use reusable templates. That could include service pages, articles or team profiles. I also confirm which content the WordPress editor will manage and where reusable Oxygen components will keep layouts consistent.

Review the current environment before making changes

For an existing Oxygen site, I review the templates, content types, plugins and hosting setup before agreeing to the work. We plan where to test changes, how to review the pages on different screens, and how the final handoff will work. Plugin licenses and hosting are scoped separately.

Frequently asked questions

Do you work on existing Oxygen websites?
Yes. I can assess a focused change or a broader rebuild. Send the site URL, your Oxygen version if known, and what needs to change.
Can I request a WordPress site instead of Webflow?
Yes. I can quote an Oxygen build if WordPress fits your publishing workflow, hosting or plugin requirements.
What can my team edit after handoff?
We agree which content your team should edit in WordPress, then review the editing workflow and templates at handoff.
