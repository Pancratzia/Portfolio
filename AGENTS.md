# Pancratzia: notes for AI agents

Production: https://www.pancratzia.com, repository `Pancratzia/Portfolio`, branch `main`.
GitHub Actions (`.github/workflows/pages.yml`) publishes `dist/` on every push.

## The site

- `dist/` is the deployable static site: 33 English pages and 33 Spanish pages under `/es/`.
- It is generated by `python3 scripts/v3/build.py` from `scripts/v3/`:
  `core.py` (head, header, footer, `t(en, es)` and `u(path)` helpers),
  `pages_home.py`, `pages_main.py`, `legacy.py`, `base.css`, `extra.css`, `site.js`.
- `legacy.py` carries long-form copy (service details, articles, legal pages) from
  commit `06b4182` in git history. To change that copy permanently, move it into
  a v3 module instead of editing `dist/` by hand.
- After every build run `python3 scripts/prepare-site.py`. It adds GTM-MJ25B2CM and
  GA4 G-8PBFVMNNQS once per page, writes localized 404 pages, `locale.js`,
  `sitemap.xml` and `robots.txt`. Never hand-edit the sitemap.
- Every change must exist in both languages.

## Rules

- Keep the brand: purple `#7136d0`, ink `#251b33`, paper `#f5f2ec`, lilac `#ddd0ef`,
  Space Grotesk + DM Sans, square corners.
- Contact is email-first (`me@pancratzia.com`). No form backend.
- Keep existing prices, maintenance terms and the localization add-on (USD 100 + USD 50/month).
- Production builds use root asset URLs. `--base-path /Portfolio` is only for local checks.
- Never commit secrets, `_site/` or `__pycache__/`.
- Update `docs/screenshots/` and `README.md` when the design changes noticeably.
